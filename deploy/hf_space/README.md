# GPU-CorruptNet demo

Detects and classifies 10 classes of GPU rendering corruption with calibrated, conformal
confidence. Pick or upload a frame, optionally inject a corruption, and see the predicted
artifact types, confidence, conformal set, OOD score, and inference latency.

Source: https://github.com/tanaymihani/gpu-corruptnet
